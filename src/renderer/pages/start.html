Tor Secret Browser

A private window onto the Tor network. All traffic — including DNS — is routed through Tor.

Try these onion services

  • DuckDuckGo — .onion search engine
  • Tor Project — project homepage
  • Facebook — official onion mirror
  • Proton Mail — encrypted mail

How it works here

  • Tor is launched automatically and your browser talks only to its local SOCKS5 proxy.
  • Each tab gets its own session and its own Tor circuits (circuit isolation).
  • WebRTC is disabled and DNS never leaves the Tor process.
  • No history, cookies, or cache are written to disk between runs.

Paste any *.onion address into the address bar, or type a search query to search over Tor.
