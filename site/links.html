Verified addresses. Every .onion below is the address published by the service itself and listed on the Tor Project's onion index at onion.torproject.org. Clearnet addresses open in any browser; .onion addresses only resolve through Tor, so use a Tor-capable browser such as this app.

How links open in Tor Secret Browser

There is one input for everything. The new-tab page has an Open a link box, and the toolbar has the address bar; both accept the same inputs.

Clearnet URL

Enter example.com or a full https:// URL. The request is sent through the local Tor daemon just like any other page, so the site you reach sees a Tor exit node — not you.

.onion address

Paste the whole 56-character ….onion name. Tor resolves it directly and the page loads over the same SOCKS5 channel. No extensions or settings to enable.

Search query

Type plain words and press Enter. They are sent to DuckDuckGo's .onion search service, so even the search is performed over Tor.

Copy from this page

Every .onion address above has a Copy button. Copy it, then paste it into the app's address bar or the new-tab Open a link box.

Why not clickable onion links here? A normal browser outside Tor cannot resolve .onion names, and clicking one would only show a connection error. Copying the address and using the app is the reliable path.
