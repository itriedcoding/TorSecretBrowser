File scanner

Inspect any file for malware indicators. Analysis runs entirely on your device using the browser's built-in cryptography — the file is never uploaded and no network request is made.

Scan a file

Drop a file below or click to choose one. Works with executables, installers, archives, documents, scripts, images — any type.

What this scanner actually checks

Every check below is performed for real, in your browser. There is no simulated step and no placeholder result.

Cryptographic hashes

Computes the file's SHA-256 and SHA-1 digests with the browser's Web Crypto API so you can compare them with any published value.

Official checksums

Compares the SHA-256 against the published checksums of the current Tor Secret Browser release, and warns if a file that claims to be one of our installers does not match.

True file type

Reads the file's magic bytes to identify what it really is, then compares that against the filename extension — the classic invoice.pdf.exe trick.

Archive inspection

For ZIP-based files it walks the central directory and lists any executables or scripts hidden inside — without trusting the outer extension.

Content indicators

Scans the bytes for real-world malware patterns: encoded PowerShell, Windows Script Host objects, download-and-run commands, Office macros, obfuscated JavaScript and URLs pointing at raw IP addresses.

Filename tricks

Flags double extensions, Windows hidden-executable extensions and the Unicode right-to-left override character used to disguise file types.

What it cannot do. This is a heuristic and integrity scanner, not a signature-based antivirus. It has no malware database and cannot recognise a brand-new or unknown threat by definition, so a clean result is not a guarantee that a file is safe. Use it alongside — not instead of — a reputable antivirus and the operating system's own warnings. Because everything runs locally, the file also has to fit in your browser's memory; very large files take longer to hash.
Official checksums. The trusted SHA-256 values for the current release are published as SHA256SUMS.txt and on the download page. Always download Tor Secret Browser from this site or its GitHub releases.
