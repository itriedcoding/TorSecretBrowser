Privacy policy

Last updated: 12 October 2026

This policy covers two separate things: this website and the Tor Secret Browser application you can download from it. It is written to match what the software actually does. If you find a discrepancy, that is a bug — please report it.

The short version

  • This website sets no analytics, advertising or tracking cookies.
  • The only cookie is a single preference cookie that records your cookie choice.
  • The application contains no telemetry and sends nothing to us.
  • We do not run accounts, mailing lists or profiles, and we hold no personal data about you.

1. This website

This site is a static set of HTML, CSS and JavaScript files. It has no user accounts, no contact forms, no comment systems and no embedded third-party content (no fonts, scripts, pixels or iframes from other providers). The JavaScript it ships runs entirely in your browser and is used only for interface behaviour such as detecting your operating system to highlight the right download, and remembering your cookie choice.

Cookies

The website itself sets exactly one cookie:

NamePurposeLifetime
tsb_consentRemembers whether you accepted or declined the cookie notice. It contains only that choice — no identifier.180 days

Both “Accept” and “Decline” write this cookie, because the point of the banner is to remember your decision. No other cookies or browser storage are used for tracking. Because no tracking takes place, there is nothing to consent to beyond this preference.

Hosting and server logs

The site is hosted on Vercel. Like any web host, Vercel may automatically record standard technical request information (such as IP address, user agent and timestamp) in server logs for security, abuse prevention and reliability. This is generated by the hosting provider, not by us, and we do not use it to identify or profile visitors. See Vercel’s privacy policy for details.

Downloads

Download links point to GitHub Releases. When you click one, you leave this site and GitHub’s own privacy policy and terms apply. We do not host your downloads or receive any report about them.

2. The application

Tor Secret Browser is a desktop application. It does not report usage, crashes or any other data to us; there is no analytics switch to disable because there is no analytics. “No telemetry switches” in our feature list means the switches themselves are absent, not merely turned off.

Everything the app keeps is stored locally, on your machine:

  • Tor state — the generated torrc, the control auth cookie and Tor’s guard state, under <app user data>/tor-data/. You can delete this folder at any time to reset your guards.
  • Browsing data — held in memory only for the lifetime of a tab session. Partitions are created without the persist: prefix, so cookies, cache and storage are not written to disk between runs.

The application does not collect, transmit or store personal data on our behalf. Your network traffic is routed through the Tor network, which is operated by the Tor Project and thousands of independent volunteers; their handling of that traffic is governed by how Tor works, not by us.

3. Data we collect

None. We do not collect, sell, rent or share personal data, because we do not receive any. There is no analytics service, no advertising network and no account system attached to this project.

4. Your rights

Regulations such as the GDPR and CCPA give people rights over personal data held about them, including access, correction and deletion. Because we hold no personal data about you, there is nothing for us to retrieve or erase on request. Hosting-related server logs are controlled by our hosting provider, Vercel; you can direct requests relating to those logs to them.

5. Children

This software and website are not directed at children and we knowingly collect no data from anyone, including children.

6. Changes to this policy

If this policy changes, the “Last updated” date above will change with it. Because the project is open source, every change is visible in the public repository.

7. Contact

Questions or corrections are welcome through the project’s issue tracker: github.com/itriedcoding/TorSecretBrowser/issues.
